# SolidityChainPro

SolidityChainPro enables decentralized, distributed ledger-based data storage and Smart Contract Execution on a scalable Node Platform.

The key benefits of using SolidityChainPro include:

- SolidityChainPro enables decentralized, distributed ledger-based
- data storage and Smart Contract
- Execution on a scalable Node

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityChainPro.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SolidityChainPro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
